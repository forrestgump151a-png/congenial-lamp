# デイリーマナー自動まとめ

LINEで毎日配信される「デイリーマナー」のメッセージを、自動でまとめて記録する仕組みです。

## 使い方（あなたがやること）

LINEで受け取ったデイリーマナーの本文を、自分のGmail（forrestgump151a@gmail.com）宛に転送してください。

- **件名または本文に「デイリーマナー」という言葉を含めてください**（例：件名「デイリーマナー 7/3」）。これが自動検出の目印になります。
- 本文はメールの**本文にテキストとして貼り付けて**ください（Word添付ファイルは読み取れません）。
- 数日分をまとめて1通で送っても大丈夫です。

## 自動で行われること

毎日 21:00（日本時間）に、Claudeの定期実行ルーチンが次を行います：

1. Gmailから直近の「デイリーマナー」メールを検索
2. 新しい配信内容を「日付／聖書箇所／主題／要点／適用」の形式で要約
3. `summaries/デイリーマナーまとめ.md` に追記し、このリポジトリにプッシュ
4. 完了通知を送信（新着がない日は何もしません）

## まとめの保存先

- [デイリーマナーまとめ.md](./デイリーマナーまとめ.md) — 新しい日付が上に来るように追記されます
