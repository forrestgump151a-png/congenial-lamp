# ACF粒子検査 規格値検索ツール

異方性導電膜(ACF)の粒子検査(一次粒子径・平均粒子径・粒子面積率)について、
品名ごとの検査OK範囲(規格値)を検索できる社内向けツールです。

## 使い方

```bash
cd acf_particle_inspection
pip install -r requirements.txt
python app.py
```

ブラウザで http://localhost:5050 を開き、品名を入力して検索します。

## データについて

現在 `data/criteria.csv` にはサンプル(ダミー)データが入っています。
実際の規格値リストが用意できたら、Webの「データ更新」画面から
CSVまたはExcel(.xlsx)をアップロードして差し替えてください。

### 必須の列(1行目のヘッダー)

| 列名 | 内容 |
|---|---|
| 品名 | 検索キーとなる製品名 |
| 一次粒子径_下限 / 一次粒子径_上限 / 一次粒子径_単位 | 一次粒子径のOK範囲 |
| 平均粒子径_下限 / 平均粒子径_上限 / 平均粒子径_単位 | 平均粒子径のOK範囲 |
| 粒子面積率_下限 / 粒子面積率_上限 / 粒子面積率_単位 | 粒子面積率のOK範囲 |
| 備考(任意) | 補足事項 |
| 更新日(任意) | 規格値の更新日 |

上限・下限のどちらか一方が空でも構いません(片側規格として扱われます)。
テンプレートは検索画面またはデータ更新画面からダウンロードできます。

アップロードすると差し替え前のデータは `data/backups/` に自動でバックアップされます。
